# MOZHNA / Можна

MOZHNA — личный финансовый помощник: показывает, сколько денег действительно свободно, помогает выгоднее удовлетворять повторяющиеся потребности и находить дополнительный доход.

Основной интерфейс — простой счётчик и проверка покупки. Android и ПК используют общий адаптивный клиент; существующие AI-ассистенты подключаются через MCP. Банковские данные, чеки и Telegram добавляются по мере проверки пользы.

**Состояние репозитория:** документация и структура для начала разработки. Приложение, API, банковские интеграции и MCP-сервер пока не реализованы. Команды запуска появятся вместе с первым работающим срезом.

## Что должен уметь продукт

- Считать доступные средства с учётом обязательств, обычных расходов, резерва и цели.
- Отвечать `МОЖНА`, `МОЖНА, АЛЕ…`, `ЩЕ НІ` или `НЕВІДОМО` и показывать причину.
- Сравнивать текущую привычку с альтернативой, помнить выбор и проверять фактический результат.
- Находить вакансии и готовить отклики на основе подтверждённых фактов пользователя.
- Использовать разрешённые аккаунты в явно заданных пределах; отправка требует отдельного разрешения.

Финансовые числа и права проверяет детерминированный код. Модель помогает извлекать сведения, предлагать варианты и готовить тексты.

## Структура

| Папка | Назначение |
| --- | --- |
| `apps/web/` | Будущий клиент для телефона и ПК |
| `services/backend/` | Будущий backend, API, MCP и worker |
| `packages/` | Выделяемые общие контракты и чистая денежная логика |
| `infra/` | Будущие конфигурации окружений и эксплуатации |
| `docs/` | Спецификации, roadmap и архитектурные решения |
| `tests/` | План проверок и синтетические примеры |
| `scripts/` | Проверка документации |
| `.github/` | Issue/PR templates, CODEOWNERS и CI |

Папка обозначает ответственность, а не отдельный микросервис. Начинаем с минимального работающего среза.
