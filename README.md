# MOZHNA / Можна

MOZHNA — облачный личный финансовый помощник. Он хранит состояние денег и планы, помогает выгоднее удовлетворять повторяющиеся потребности и находить дополнительный доход. Фоновые задачи выполняются в облаке, даже когда телефон, браузер или внешний AI-ассистент закрыты.

**Состояние:** архитектура, документация и GitHub scaffold. Приложение и облачная инфраструктура ещё не развёрнуты; банковские и LLM-подключения не созданы. Выбор стека — действующее техническое решение по поручению владельца, а не заявление о готовой реализации.

## Выбранный стек

| Слой | Язык и технологии | Назначение |
| --- | --- | --- |
| Клиент | TypeScript, React, Vite, CSS; PWA | Общий адаптивный интерфейс для ПК, Android, iPhone и планшетов |
| Облачный backend | Python, FastAPI, Pydantic, SQLAlchemy, Alembic | Финансы, планы, API, MCP, интеграции и LLM adapters |
| Состояние | SQL, PostgreSQL | Данные, версии, задания, outbox, approvals и результаты |
| Фоновые процессы | Python; отдельные worker и scheduler из backend image | Синхронизация, обработка чеков, поиск, вызовы моделей |
| Файлы | Приватное S3-совместимое object storage | Чеки и документы; временные ограниченные ссылки |
| Доставка | Docker, GitHub Actions | Один воспроизводимый backend image и сборка web-клиента |
| Мобильная упаковка | Capacitor, когда нужен магазин или native API | Повторное использование web-клиента на iOS/Android |

TypeScript отвечает за интерфейс; Python — за доменную и агентную работу; SQL — за долговечное состояние. Обоснование и альтернативы: [STACK](docs/STACK.md).

## Как это работает

1. Пользователь входит с любого поддерживаемого устройства и видит одно облачное состояние.
2. Проверка покупки выполняется детерминированным ядром, без LLM.
3. Длительная команда получает job ID и сохраняется в PostgreSQL.
4. Worker выполняет разрешённые шаги, сохраняет прогресс и результат.
5. Пользователь возвращается с другого устройства или через MCP и продолжает тот же план.

Для разных моделей предусмотрены два независимых пути: **исходящие LLM adapters** для фоновой облачной работы и **входящий remote MCP** для внешних ассистентов. Подписка в отдельном AI-клиенте не заменяет настроенный облачный inference provider.

## Разработка

Читайте [CONTRIBUTING](CONTRIBUTING.md) и [AGENTS](AGENTS.md). Текущая проверка:

```bash
python3 scripts/check_docs.py
```

Она проверяет документы, локальные ссылки и JSON-примеры, а не runtime. Проверенные команды запуска и lockfiles появятся вместе с кодом. Лицензия распространения пока не выбрана владельцем.
