# Web-клиент

Будущий адаптивный клиент для Android и ПК: ручное состояние, счётчик, проверка покупки, планы и доверенные подтверждения. Runtime ещё нет.

React/TypeScript предложен в исходниках; Next.js против тонкого React-клиента остаётся выбором до реализации. Здесь появятся исходники, package manifest, lockfile и проверенные команды запуска вместе с первым срезом. См. [архитектуру](../../docs/ARCHITECTURE.md).
