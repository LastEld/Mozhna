# Инфраструктура

Здесь появятся конфигурации локального и целевого окружений, миграций и backup/restore. Сейчас hosting и deployment отсутствуют.

Не коммитить credentials, реальные базы, secrets или state инфраструктуры. При добавлении runtime описать переменные в `.env.example` без значений секретов, команды запуска и восстановления. До выбора окружения фиктивный Docker Compose не нужен.

Требования: [OPERATIONS](../docs/OPERATIONS.md).
