# Документы MOZHNA

Это обычная рабочая документация. Описанные возможности являются требованиями, пока реализация и проверки не подтверждены в репозитории.

1. [PRODUCT](PRODUCT.md) — что строим и зачем.
2. [CONTEXT](CONTEXT.md) — какие исходные решения восстановлены и где есть расхождения.
3. [REQUIREMENTS](REQUIREMENTS.md) — требования с критериями приёмки.
4. [ROADMAP](ROADMAP.md) и [BACKLOG](BACKLOG.md) — последовательность работы.
5. [ARCHITECTURE](ARCHITECTURE.md), [MONEY](MONEY.md), [DATA_MODEL](DATA_MODEL.md) — технический проект.
6. [INTEGRATIONS](INTEGRATIONS.md) и [ACTIONS](ACTIONS.md) — доступ к внешним системам.
7. [VALIDATION](VALIDATION.md) и [OPERATIONS](OPERATIONS.md) — проверка и эксплуатация.
8. [Архитектурные решения](adr/README.md) — статусы и причины решений.

`REQUIREMENT` — требование продукта; `PROPOSED` — проектное предложение; `IMPLEMENTED` допускается только со ссылкой на работающий код и результат проверки. Ни один документ этой инициализации не заявляет реализованный runtime.
