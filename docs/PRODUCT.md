# Продукт

MOZHNA — облачное приложение: помогает понять свободные деньги, последствия покупки и способы улучшить положение в долгой перспективе. ПК, Android, iPhone и планшеты используют одно состояние. Задания выполняются сервером и переживают закрытие клиента.

## Основные сценарии

**Деньги сейчас.** Пользователь вводит остаток, обязательства, резерв и одну цель. Получает предел траты с горизонтом и качеством данных. Проверка покупки показывает оставшийся запас и затронутые платежи.

**Повторяющаяся потребность.** Пользователь регулярно покупает небольшой напиток на работу. MOZHNA сравнивает цену за порцию, хранение, удобство, расходы запуска и риск отходов. Пользователь может попробовать альтернативу, отказаться или сохранить текущую привычку.

**Результат плана.** Принятое изменение сохраняется между сессиями ассистента. Фактические покупки сравниваются с явно заданным baseline; потенциальная экономия не прибавляется к балансу.

**Дополнительный доход.** Продукт показывает ближайшую нехватку и устойчивый разрыв дохода. В рамках разрешений ищет подходящие вакансии, готовит проверяемые черновики и позднее исполняет подтверждённые отклики.

**Неясная покупка.** Чек или транзакция не позволяют уверенно определить назначение. Пользователь получает короткое уточнение; его ответ сохраняется отдельно от исходных данных.

## UX

Главный экран — деньги, качество данных, ближайшее последствие и понятное действие. Разговор может оставаться в привычном AI-клиенте через remote MCP; фоновая работа использует отдельные облачные LLM adapters. Украинские состояния: `МОЖНА`, `МОЖНА, АЛЕ…`, `ЩЕ НІ`, `НЕВІДОМО`.

Точные экраны остаются проектным выбором: v1 предлагает «Зараз / План / Рух», v2 — «Зараз / Можливості / Плани». Для первого денежного среза достаточно облачного ввода состояния и проверки покупки. Responsive layout и resume на другом устройстве входят сразу; см. [CLIENTS](CLIENTS.md).

## Границы

Начальный pilot: один владелец, одна валюта, одна цель и ручные данные в облаке. Ownership, authentication и device sessions реализуются сразу. Это ограничение pilot, не утверждение о текущих пользовательских счетах.

В первой версии нет движения банковских денег, автоматического запрета платежа, покупки финансовых продуктов, сложной бухгалтерии, семейного бюджета или неограниченных автономных откликов.

MOZHNA показывает последствия без стыда и давления. Отказ от альтернативы сохраняется как ограничение, а не ошибка пользователя. Выгода оценивается вместе с удобством, временем и сохранением нужного результата.
