# Эксплуатация

Статус: требования к будущему runtime. Hosting, домен, deployment и secrets сейчас не настроены.

Первый работающий срез должен иметь документированные запуск, остановку, миграции, export/delete и backup/restore. Конкретные команды добавляются после выбора stack и реальной проверки.

| Сигнал | Для чего |
| --- | --- |
| as_of и last successful sync | Видеть свежесть денежного основания |
| reconciliation difference | Обнаружить конфликт источников |
| UNKNOWN reason | Понять, какое поле исправить |
| Job state/age/attempt count | Отличать ожидание модели, ошибку provider и зависшую работу |
| OUTCOME_UNKNOWN | Требовать сверку внешней отправки |
| Budget/cost | Не запускать скрытый платный fallback |

Журналы содержат correlation IDs и минимальные причины, без raw выписок, CV и токенов. Ключи шифрования отделены от прикладных данных. Retention определяется до накопления реальных данных.

Восстановление проверяет целостность состояния, версии политики, действительность consent и статусы отправок. Очередь после restore не воспроизводит внешние side effects автоматически. Старый backup не восстанавливает отозванный мандат.

При ошибке расчёта: отключить зависимое разрешающее решение, сохранить техническое основание, исправить policy, прогнать сценарии и сравнение версий. При ошибке отправки: остановить соответствующий connector, сверить внешний исход, затем восстанавливать работу.
