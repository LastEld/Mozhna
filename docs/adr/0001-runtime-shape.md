# Runtime и первый срез

Статус: PROPOSED. Дата: 2026-09-07. Явное принятие владельцем пока не зафиксировано.

## Контекст

v1 задаёт manual-first; v2 предлагает полный цикл привычки и ранний MCP. Размещение ядра и web framework различаются.

## Предложение

Один backend, PostgreSQL и общий worker; внутренние модули. Общий безопасный старт — денежный контракт и ручное состояние. Ранний Plan/MCP и независимый Earn требуют явного выбора следующего среза.

## Последствия и проверка

Выбрать FastAPI/runtime dependencies, размещение Money и Next.js либо другой React-клиент перед первым кодом. Не создавать микросервисы из названий папок.
