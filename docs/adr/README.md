# Архитектурные решения

ADR хранит один выбор: контекст, решение, последствия и статус. PROPOSED не означает принятие владельцем. ACCEPTED сопровождается ссылкой на явное решение; SUPERSEDED — ссылкой на замену. Ни один ADR в bootstrap не имеет статуса ACCEPTED.
