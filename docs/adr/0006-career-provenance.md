# Карьерные факты

Статус: PROPOSED. Дата: 2026-09-07. Явное принятие владельцем пока не зафиксировано.

## Контекст

LLM может адаптировать формулировки, но не изобретать опыт, язык, диплом или право на работу.

## Предложение

Канонический ProfileFact с источником и подтверждением; draft содержит factual diff и profile version.

## Последствия и проверка

Неизвестный существенный факт требует уточнения. Финансовое положение не раскрывается работодателю. Не использовать некалиброванные вероятности оффера.
