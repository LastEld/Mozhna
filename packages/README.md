# Общие компоненты

Здесь будут только действительно переиспользуемые чистые контракты или библиотеки. В исходном roadmap предлагалось отдельное Money Kernel; v2 предлагает начать внутренними модулями backend. Решение о размещении фиксируется до первого кода.

Не создавать package на каждую будущую функцию. Транспортные схемы генерируются из одного канонического контракта, когда появляется второй потребитель. См. [архитектуру](../docs/ARCHITECTURE.md).
