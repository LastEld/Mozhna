# Безопасность

Текущая версия — однопользовательская alpha. Реализованы owner checks, версии, серверные сессии, CSRF, origin policy, HTTPS/Secure cookie в production и отказ при отсутствии пароля. [Известные ограничения](docs/IMPLEMENTATION.md) включают отсутствие OIDC/MFA, distributed login limiter, MCP OAuth, подтверждённого restore и полноценной политики удаления backups.

Не публикуйте ключи, CV, банковские выписки и личные данные в issues. О проблеме сообщайте владельцу через доступный приватный канал GitHub; не добавляйте в отчёт действующий секрет. Security reporting channel отдельно пока не настроен.

MCP bearer даёт доступ на чтение ко всему пространству одного владельца. Передавайте его только доверенному клиенту; отзыв требует ротации переменной и перезапуска API. Пароль владельца и MCP credential различны. Приложение не принимает произвольные внешние URL для provider requests.

Нет tools для отправки откликов, платежей или покупок. Лимит jobs не равен денежному бюджету; paid inference выключен по умолчанию. Уже отправленный провайдеру запрос не отзывается cancel, но canceled result не восстанавливается.

Не коммитьте `.env`, реальные данные, sessions или backups. Примеры и тесты используют только синтетические данные. Для публичного релиза выполните оставшиеся gates из [ROADMAP](docs/ROADMAP.md).
