# Безопасность

Текущая версия — однопользовательская alpha. Реализованы owner checks, версии, серверные сессии, CSRF, строгая origin policy, HTTPS/Secure cookie в production и отказ при отсутствии пароля. Счётчик неудачных входов хранится в БД и общий для процессов: 8 попыток за 5 минут на аккаунт. Записывающие API-запросы повторно проверяют сессию в транзакции под блокировкой владельца; scheduler не создаёт задания по удалённому состоянию. Тела API/MCP-запросов ограничены 2 500 000 байтами, включая chunked transfer.

[Известные ограничения](docs/IMPLEMENTATION.md) включают отсутствие OIDC/MFA, MCP OAuth, подтверждённого облачного restore и полной политики удаления backups. Общий лимит входа позволяет временную блокировку новых входов атакующим; это не многопользовательская система auth.

Не публикуйте ключи, CV, банковские выписки и личные данные в issues. О проблеме сообщайте владельцу через доступный приватный канал GitHub; не добавляйте в отчёт действующий секрет. Security reporting channel отдельно пока не настроен.

MCP bearer даёт доступ на чтение ко всему пространству одного владельца. Передавайте его только доверенному клиенту; отзыв требует ротации переменной и перезапуска API. Пароль владельца и MCP credential различны. Приложение не принимает произвольные внешние URL для provider requests.

Нет tools для отправки откликов, платежей или покупок. Лимит jobs не равен денежному бюджету; paid inference выключен по умолчанию. Уже отправленный провайдеру запрос не отзывается cancel, но canceled result не восстанавливается.

При восстановлении базы остановите все runtime-процессы и выполните [карантин](docs/RECOVERY.md) до повторного запуска. Команда отзывает восстановленные сессии, удаляет расписания и отменяет незавершённые jobs; финансовые records сохраняет. Секреты окружения, включая MCP bearer, этой командой не меняются.

Не коммитьте `.env`, реальные данные, sessions или backups. Примеры и тесты используют только синтетические данные. Для публичного релиза выполните оставшиеся gates из [ROADMAP](docs/ROADMAP.md).
