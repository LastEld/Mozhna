# Безопасность

Продукт ещё не реализован; этот репозиторий не следует использовать для хранения реальных финансовых данных или сессий.

Не размещайте секреты, полные выписки, чеки, CV и session cookies в Issues, PR, fixtures или logs. Используйте синтетические воспроизведения.

Для уязвимости используйте приватное сообщение через GitHub Security Advisories, если private reporting включён владельцем. Если недоступно, сначала запросите приватный канал у владельца без публикации чувствительных подробностей. Специальный security email и SLA пока не назначены.

Для будущего runtime обязательны owner/scopes, минимизация данных, шифрование provider tokens, отзыв доступа, воспроизводимый расчёт и проверяемое разрешение внешнего действия. Подробности: [ACTIONS](docs/ACTIONS.md) и [OPERATIONS](docs/OPERATIONS.md).
